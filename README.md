# Shopify Database Project

## Overview

This project is a relational database designed to manage and analyze data for a Shopify e-commerce store. The database organizes key business information, including customers, products, orders, payments, and order details, while establishing relationships between these entities to maintain accurate and efficient data management.

The project demonstrates the use of SQL Server and T-SQL to build a structured e-commerce database and perform queries that provide insights into sales performance, customer activity, product performance, and overall store operations.

## Key Features

- Relational database design for an e-commerce business
- Customer and product management
- Order and order-detail tracking
- Sales and revenue analysis
- Primary and foreign key relationships
- Data integrity and validation
- SQL queries using JOINs, aggregations, subqueries, and filtering
- Business-focused analysis of Shopify store data

## Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

## Project Goals

The goal of this project is to demonstrate practical SQL and database-development skills by creating a realistic e-commerce database and using SQL queries to transform raw data into meaningful business insights.
